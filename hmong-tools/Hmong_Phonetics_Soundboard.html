💡 How Multi-Letter Hmong Consonants Work (Up to 4 Letters):
White Hmong builds complex consonants in predictable layers from left to right—you never pronounce the letters separately:
1. Pre-nasal (n-) = hum through nose first + 2. Core Stop / Affricate (p, t, c, k, q, ts, tx) + 3. Lateral release (-l-) = tongue flick + 4. Aspiration (-h) = strong puff of air = Example: n + p + l + h = nplh (nplhaib "ring")
