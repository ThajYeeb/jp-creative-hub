Slot Order Role White Hmong (RPA) Examples Grammar Rule
1. Subject Pronoun / Noun kuv (I), koj (you), nws (he/she), peb (we), nej (you pl.), lawv (they) Starts the clause (SVO order).
2. Tense / Aspect Time Marker yuav (will), tau (did/got), tab tom (currently -ing) Placed after Subject, before puas / tsis / Verb.
3. Question Yes/No Particle puas (do/does/is/are?) Placed directly before the verb (or before tsis / modal).
4. Negation Negative Particle tsis (not / do not) Placed right before the verb: Kuv tsis paub.
5. Verb Chain Modal + Main Verb xav (want), nyiam (like), kawm (learn), hais (speak), mus (go), nyob (live/be), pab (help), nyeem (read), pom (see) Verbs never conjugate for tense or person.
6. Object / Tail Noun / Classifier / Wh-word lus Hmoob, ib tug phooj ywg, ob phau ntawv, dab tsi (what), qhov twg (where) Classifiers follow Number + Classifier + Noun.
